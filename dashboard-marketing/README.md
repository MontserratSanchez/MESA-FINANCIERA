# Dashboard de marketing (terracota)

Tablero interactivo en un solo archivo (`index.html`) para un análisis exploratorio básico de campañas de marketing.

- **Datos:** sintéticos, generados en el navegador con semilla fija (240 registros: 12 meses × 5 canales × 4 regiones). No representan resultados reales.
- **Interacción:** filtros por canal, región y rango de meses; clic en barras de canal; tabla ordenable; descarga del CSV filtrado.
- **Widgets incrustados:** muro de Padlet "Conceptos clave de marketing" y agente de voz de ElevenLabs (`agent_5001m67360kae29atxtjjvgrbvq3`).

Ábrelo desde GitHub Pages (https) para que el agente de voz cargue correctamente.
